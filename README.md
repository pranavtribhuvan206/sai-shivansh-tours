# Sai Shivansh Tours & Travels

Official website for **Sai Shivansh Tours & Travels** — Shirdi's trusted car rental, pilgrimage travel, and outstation cab booking service.

> **Safe Journey, Happy Memories**

---

## 🚖 Features & Overview

- **Fleet Range**: Swift Dzire, Maruti Ertiga, Toyota Innova, Innova Crysta, Tavera, Suzuki Ciaz, and luxury 12–26 Seater Tempo Travellers / Force Urbania.
- **Transparent Rates**: Standard per-kilometre rates from **₹11–₹25/km** and **Monthly Rentals at ₹35,000/month**.
- **Services**: Shirdi Pilgrimage Darshan, Airport Transfers (Shirdi SAG, Pune PNQ, Mumbai BOM), Local Sightseeing, Outstation Round Trips, and Group Travel.
- **Direct Actions**: Instant WhatsApp booking with prefilled vehicle requests, direct phone helpline, and online booking inquiry forms.
- **Design System**: Royal Burgundy / Maroon & Warm-Brown palette with soft cream backgrounds and subtle gold accents.

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: Cloudflare Pages / Static Jamstack

---

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd sai-shivansh-tours
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:5173` (or the terminal port) in your browser.

### 4. Build for production
```bash
npm run build
```
The production-ready static bundle will be generated in the `dist/` directory.
